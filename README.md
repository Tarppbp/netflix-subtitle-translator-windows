# Netflix 日语字幕本地翻译 · Windows

在 Windows 11 上读取 Netflix 正在显示的日文字幕，用本机 Ollama 翻成简体中文。桌面控制面板统一管理翻译开关、模型、字体和字幕位置。

- 仅显示中文时，译文放在原日文位置。双语模式下，中文显示在原日文上方。
- 使用 Windows 无障碍接口或 Edge 扩展读取已经显示的字幕。桌面端与翻译引擎通过本机回环地址通信。
- 支持重复对白缓存。首次出现的字幕需要等待模型生成译文。

## 安装

1. 下载并解压 Windows 安装包，或下载本仓库源码。
2. 双击 `Install.cmd`。首次安装需要联网下载 Ollama 和默认的 Qwen3 4B Instruct 模型。
3. 以后双击 `Start.cmd`，在桌面面板点击「开始翻译」。在 Netflix 播放器中选择日文字幕。

启用仅中文和跟随原字幕位置需要 [加载配套 Edge 扩展](使用说明.md#字幕扩展)。

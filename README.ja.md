# Netflix 字幕ローカル翻訳 · Windows

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

Windows 11 で Netflix に表示された字幕を読み取り、PC 上の Ollama で翻訳します。翻訳元・翻訳先の言語、モデル、フォント、字幕の位置はデスクトップの操作パネルで変更できます。

- 13 種類の選択肢から翻訳元と翻訳先を個別に選べます。初期設定は日本語から簡体字中国語への翻訳です。英語から日本語、フランス語から韓国語などの組み合わせも選べます。
- 翻訳のみ表示する場合は元の字幕と同じ位置に、二言語表示では元の字幕の上に訳文を表示します。
- 翻訳処理は PC 内で行い、プレーヤーに表示済みの字幕テキストを使用します。

## 推奨環境

| 項目 | 推奨構成 |
| --- | --- |
| OS | Windows 11 x64。同梱の字幕拡張機能を使う場合は Microsoft Edge が必要です。 |
| GPU | NVIDIA GeForce RTX 4060（デスクトップ版、8 GB）、または VRAM 8 GB 以上の上位モデルを推奨します。CUDA 対応の NVIDIA ドライバーを使用してください。 |
| メモリ | Netflix、ブラウザー、ローカルモデルの動作に 16 GB 以上を推奨します。 |
| ストレージ | インストール用の一時ファイル、Ollama、既定モデル用に SSD の空き容量 10 GB 以上を推奨します。 |
| モデル | 既定は `qwen3:4b-instruct`。初回のモデルダウンロードは約 2.5 GB です。 |

RTX 4060 は推奨の目安です。この GPU での再生中の遅延は未測定です。検証環境は Core Ultra 9 285H、RTX 5060 Laptop GPU（VRAM 8 GB）、メモリ 32 GB です。既定モデルは測定時に約 2.68 GiB の VRAM を使用しました。 [テスト報告（中国語）](测试报告.md)

## 使い方

1. [GitHub Releases](https://github.com/Tarppbp/netflix-subtitle-translator-windows/releases/latest) から Windows 用 ZIP をダウンロードして展開し、`Install.cmd` を実行します。初回は Ollama と既定の Qwen3 モデルをダウンロードします。
2. Netflix で字幕トラックを選びます。操作パネルで同じ言語を翻訳元に設定し、翻訳先を選んで開始します。次回は `Start.cmd` で操作パネルを開けます。
3. 訳文のみ表示する場合は、`edge://extensions` で開発者モードを有効にし、パッケージ化されていない拡張機能として同梱の `extension` フォルダーを読み込みます。その後、Netflix の再生ページを再読み込みします。

操作パネルは簡体字中国語です。詳しい設定は[利用ガイド（中国語）](使用说明.md)、検証範囲は[テスト報告（中国語）](测试报告.md)をご覧ください。本プロジェクトは独立して開発されています。
